A program that writes the funniest one-line review of its own Monday — one star, 126 characters, no title, no explanation — to `entry.txt`. Entry for make.fun's "Monday, Reviewed in One Line" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
cat /tmp/out/entry.txt
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and exits 0. The output is a fixed constant, so two runs are byte-identical: no clock, no randomness, no network.
